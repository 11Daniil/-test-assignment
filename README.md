# Banki.shop

Тестовое задание — страница интернет-магазина по [макету Figma](https://www.figma.com/file/6LxPDEsauEGanhR2nDW68X/Banki.shop?node-id=0%3A1).

Проект сделан на Vue 2 (Options API), для сборки используется Webpack 5.

## Что реализовано

- поиск по названию картины;
- состояния кнопки «Купить», «Обрабатывается» и «В корзине»;
- сохранение корзины после перезагрузки страницы;
- модальная карточка товара с описанием, ценой и галереей;
- управление модальным окном с клавиатуры;
- адаптивная вёрстка, включая ширину 360 px.

## Запуск

Для проекта использовались Node.js `16.20.2` и npm `8.19.4`.

Если установлен nvm:

```bash
nvm use
```

Установить зависимости и запустить dev-сервер:

```bash
npm ci
npm run dev
```

После запуска страница будет доступна на [http://localhost:8080](http://localhost:8080).

`npm ci` использует версии из `package-lock.json`, поэтому результат установки будет таким же, как в CI. `npm install` нужен в основном при добавлении или обновлении зависимостей.

## Команды

```bash
npm run dev            # dev-сервер
npm run build          # production-сборка
npm run lint           # ESLint
npm run format:check   # проверка форматирования
npm test               # тесты Jest
npm run validate       # все проверки и сборка
```

Готовая production-сборка появится в папке `dist`.

## Структура

```text
src/
├── components/     Vue-компоненты
├── data/           данные товаров
├── domain/         поиск, цены и состояния покупки
├── repositories/   работа с localStorage
└── views/          композиция страницы
tests/              тесты
```

Vuex здесь не используется: для одной страницы с небольшим объёмом состояния он бы только усложнил проект.

## Примечание

Изображения картин загружаются из Wikimedia Commons. Без интернета вместо них будет показан placeholder.
